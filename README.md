# EportfolioCaparas E-Portfolio — Ederlyn H. Caparas
 Object-Oriented Programming

---

 Features

- Single Page Application — Smooth navigation between Home, Midterm, Final, and Contact pages without full reloads
- Project Cards — Midterm outputs displayed in a responsive grid, each with a title, icon, and short reflection
- Modal / Lightbox Viewer — Clicking "View Project" opens a dark-themed popup that embeds PDFs or displays images inline; closes via the X button, clicking outside, or pressing Escape
- Responsive Design — Fully functional on mobile, tablet, and desktop with a collapsible hamburger menu
- Dark Glassmorphic UI — Modern dark theme with glow effects, animated background grid, and smooth card hover transitions
- Animated Hero Section — Home page features a staggered text reveal and a 3D-tilting Java code block visual
- Contact Page — Displays email and GitHub repository with clickable links
- Final Page Placeholder — Reserved section for Final period outputs using the same card structure
